# Security Policy

## Supported versions

Report issues against `main`. There are no long-term support branches yet.

## Reporting a vulnerability

Email **shaneawall@gmail.com** with:

- A description of the issue
- Steps to reproduce
- Impact (crash, RCE, data leak, etc.)

Please do **not** open a public GitHub issue for security reports.

We will acknowledge when we can and fix what is in scope (this is a local
Godot game; most "vulns" will be crashes or bad asset loads).
