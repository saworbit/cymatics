## 1. FluidSimulator

**Inherits:** `Node`  
**File:** `scripts/fluid_simulator.gd`  
**Singleton:** Autoload as `FluidSimulator`

Owns the isolated `RenderingDevice` compute pipeline, dispatches GLSL compute passes, and manages the 120-layer VRAM snapshot ring buffer.

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `grid_size` | `Vector2i` | `Vector2i(256, 144)` | Simulation domain resolution. |
| `jacobi_iterations` | `int` | `20` | Pressure Poisson solver relaxation steps per substep. |
| `sub_steps` | `int` | `3` | Number of compute substeps per rendered frame (180 Hz physics). |
| `viscosity` | `float` | `0.0001` | Fluid kinematic viscosity ($\mu$). |
| `vorticity` | `float` | `0.35` | Vorticity confinement force multiplier ($\epsilon$). |
| `surface_tension` | `float` | `0.05` | Viscoelastic filament cohesion coefficient ($\sigma$). |
| `dissipation` | `float` | `0.998` | Per-frame velocity and dye decay factor. |
| `history_depth` | `int` | `120` | Layer count of the `Texture2DArray` rollback ring buffer. |

### Methods

#### `step_simulation(dt: float, frame_idx: int) -> void`
Executes all fluid compute passes (advection, splats, ball physics, divergence, pressure, projection), captures a VRAM layer snapshot for `frame_idx`, and submits commands to the GPU.

#### `rollback_to_vram_layer(target_frame: int) -> void`
Restores the velocity and dye textures from VRAM layer `(target_frame % 120)` in $<0.02\text{ ms}$ without CPU data transfer.

#### `inject_force(world_pos: Vector2, force: Vector2, radius: float, color: Color) -> void`
Enqueues a Gaussian force and dye splat to be processed during the next compute substep.

#### `inject_dye(world_pos: Vector2, color: Color, radius: float) -> void`
Enqueues a dye injection splat without imparting velocity.

#### `get_average_kinetic_energy() -> float`
Returns the integrated kinetic energy of the fluid field (updated asynchronously for audio modulation).

## 2. Paddle

**Inherits:** `CharacterBody2D`  
**File:** `scripts/paddle.gd`

Controls player or AI paddle dynamics and fluid displacement.

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `player_id` | `int` | `0` | `0` = Player 1 (Left), `1` = Player 2 (Right). |
| `max_speed` | `float` | `600.0` | Peak paddle movement velocity in pixels/sec. |
| `stir_strength` | `float` | `800.0` | Velocity impulse injected into fluid during movement. |
| `suck_strength` | `float` | `450.0` | Radial suction force magnitude. |
| `blast_max_charge` | `float` | `2.0` | Seconds required to achieve maximum blast charge. |
| `parry_window_frames`| `int` | `4` | Tolerance window ($\pm\text{frames}$) for executing a counter-vortex parry. |

### Methods

#### `apply_input(input: InputState) -> void`
Applies an input snapshot to update position, charge blasts, and inject wake forces into the fluid simulation.

#### `trigger_parry() -> void`
Executes an immediate counter-vortex shockwave, spawns a 4-point star burst, and inverts ball spin.

## 3. Ball (SSBO Visual Proxy)

**Inherits:** `Node2D`  
**File:** `scripts/ball_proxy.gd`

Visual and gameplay representation of the ball. The physical trajectory is computed directly in the GPU `cymatics_ball.glsl` compute shader via an SSBO.

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `base_speed` | `float` | `600.0` | Baseline initial velocity magnitude. |
| `max_speed` | `float` | `1800.0` | Absolute terminal velocity cap. |
| `mass` | `float` | `1.0` | Physical mass parameter. |
| `base_coupling` | `float` | `0.7` | Base fluid coupling coefficient ($\kappa_{\text{base}}$). |
| `magnus_multiplier` | `float` | `150.0` | Lateral curve force scalar generated by spin. |

## 4. VFXManager

**Inherits:** `Node2D`  
**File:** `scripts/vfx_manager.gd`  
**Singleton:** Autoload as `VFXManager`

Manages pooling and triggering of screen-space refractive shockwaves, anamorphic star bursts, and polar vortex lenses.

### Methods

#### `spawn_shockwave(position: Vector2, color: Color, max_radius: float, duration: float) -> void`
Spawns a refractive annular shockwave ring.

#### `spawn_star_burst(position: Vector2, color: Color, scale: float) -> void`
Spawns a 4-point anamorphic diffraction flare on parry or goal impact.

#### `trigger_polar_vortex(paddle_pos: Vector2, active: bool) -> void`
Activates or deactivates the polar coordinate swirl distortion around a sucking paddle.

## 6. RollbackManager

**Inherits:** `Node`  
**File:** `scripts/network/rollback_manager.gd`  
**Singleton:** Autoload as `RollbackManager`

Coordinates custom UDP networking, input buffers, prediction, and VRAM layer rewinds.

### Methods

#### `send_input_packet(input: InputState) -> void`
Transmits the current input along with the preceding 2 frames (triple redundancy) over UDP.

#### `execute_rollback(target_frame: int) -> void`
Restores the GPU VRAM snapshot layer and CPU `GameState` for `target_frame`, then fast-forward resimulates to `current_frame`.

## 7. AudioManager & CymaticsAudioDSP

### `AudioManager` (GDScript Orchestrator)
**Inherits:** `Node`  
**File:** `scripts/audio/audio_manager.gd`

Gathers fluid kinetic energy, ball velocity, and paddle metrics at 60 Hz and sets parameters on the native C++ DSP node.

### `CymaticsAudioDSP` (GDExtension C++ Core)
**Inherits:** `Node`  
**File:** `src/audio_dsp.cpp`

High-throughput, SIMD-accelerated procedural synthesis engine running directly on the Godot audio thread.

## 8. InputState & GameState

```gdscript
class_name InputState
extends RefCounted

var frame: int = 0
var player_id: int = 0
var dir: Vector2 = Vector2.ZERO
var suck: bool = false
var blast: bool = false
var blast_charge: float = 0.0

func serialize() -> PackedByteArray:
    var buf := PackedByteArray()
    buf.resize(24)
    return buf

static func deserialize(bytes: PackedByteArray) -> InputState:
    return InputState.new()
```

```gdscript
class_name GameState
extends RefCounted

var frame: int
var ball_position: Vector2
var ball_velocity: Vector2
var ball_spin: float
var paddle_positions: Array[Vector2] = [Vector2.ZERO, Vector2.ZERO]
var paddle_velocities: Array[Vector2] = [Vector2.ZERO, Vector2.ZERO]
var blast_charges: Array[float] = [0.0, 0.0]
var momentum: Array[float] = [0.0, 0.0]
var scores: Array[int] = [0, 0]
```
